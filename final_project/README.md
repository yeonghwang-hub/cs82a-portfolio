# The Impact of Age, Nationality, and Race Location on Marathon Time
Analysis and Visualization Data to support how age, nationality and race location affect one's marathon time.

## Problem Statement
How do age, nationality, and race location influence marathon finish times? Given a table of marathon times in order sorted by gender, analyze how other factors influence one's time.

## Dataset
-Source: [marathon.csv](https://www.kaggle.com/datasets/evgenyarbatov/marathon-running-times)
